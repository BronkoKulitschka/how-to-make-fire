# How to Make Fire · v0.3

Ein 3D-Versuch zur Anzündmechanik. Am vorbereiteten Holz liegen drei Streichhölzer in ihrer Schachtel. Maus und Touch greifen direkt an den Fingerspitzen. Einen Versuch von vorn beginnen kann man durch Neuladen.

## Funktionsweise

Der Streichholzkopf muss ein Stück über die Reibfläche gleiten. Ein angerissenes Holz brennt im Spiel acht Sekunden. Die feinen Späne nehmen Wärme auf, solange die Flamme nah genug ist. Unterbricht der Spieler den Kontakt zu früh, kühlen sie ab. Sobald die Späne selbst brennen, greift die Flamme auf die darüberliegenden dünnen Zweige und anschließend auf die größeren Holzstücke über. Der Aufbau ist für diesen Versuch trocken und locker vorbereitet. Das Timing ist für das Spiel verkürzt.

GitHub Pages kann die Dateien direkt aus main ausliefern. Lokal lässt sich index.html im Browser öffnen.
